# ReversingEverything

Taking things apart to see how they work. This repository collects reverse-engineering notes, mods, and tools for games, with a focus on C#/.NET.

## Games

- [How to Pronounce Iwan](games/How%20To%20Pronounce%20Iwan/NOTAS.MD): Unity game notes covering gameplay systems, code findings, screenshots, and open questions.

## Using this repository

Game-specific work lives in `games/<game name>/`. Keep notes in the game folder and use its `mods/` and `tools/` directories for related work.

Start notes for another game with the [game reverse-engineering notes template](games/NOTES_TEMPLATE.MD).
