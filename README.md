# ReversingEverything

Taking things apart to see how they work. This repository collects reverse-engineering notes, mods, and tools for games, with a focus on C#/.NET.

## Games

- [How to Pronounce Iwan](games/How%20To%20Pronounce%20Iwan/): game folder with [reverse-engineering notes](games/How%20To%20Pronounce%20Iwan/NOTAS.md), mods, and tools.

## Using this repository

Game-specific work lives in `games/<game name>/`. Keep notes in the game folder and use its `mods/` and `tools/` directories for related work.

Start notes for another game with the [game reverse-engineering notes template](games/NOTES_TEMPLATE.MD).

## Tools and environment

This project uses reverse-engineering techniques and [ILSpy](https://github.com/icsharpcode/ILSpy) to inspect game files and .NET assemblies, understand how games work, and support analysis, modding, and tool development. The operating system used for this work is Linux.
